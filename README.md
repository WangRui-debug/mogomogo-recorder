# もごもご录音页：GitHub Pages 版

日语收录页面：22句原稿与振假名、H/M录音、回听、重录、选用、自评、实时频谱及ZIP导出。

## 参考音频政策

自2026-10-09起，本工具不提供、加载或打包参考音频，页面不设置试听或参考文件选择入口。录制者按照文字指引与担当者练习。原15句录制文本保持不变，另新增7句数字和地址原稿；旧会话仍可打开和导出，导出时不再附带旧参考来源字段。

当前网页及下载包不含参考录音，但撤下文件不能回收他人已下载的副本或浏览器缓存。旧公开仓库历史及旧发布产物需要单独处理，不能仅凭当前文件删除就认定全部撤回。

## 使用与数据保存

- 网址：https://wangrui-debug.github.io/mogomogo-recorder/
- 录音仅保存在当前浏览器IndexedDB，不自动上传服务器或Drive；全部采用后自动发起ZIP下载，再交给担当者。
- 使用匿名话者ID。清除浏览器数据前务必导出录音。
- 页面没有登录限制；noindex不构成访问控制。部署项目仅包含site目录。
- 普通发话与もごもご为同文本配对，不是逐帧对齐。PCM16单声道，采用浏览器实际采样率，不额外归一化或去静音。

## 预览、测试与发布

```bash
python3 preview.py --port 8766
python3 tools/verify_public.py
python3 tools/test_public.py --url http://localhost:8766/preview/
python3 tools/package.py
```

本地预览：http://localhost:8766/preview/。远程服务器需要端口转发。浏览器测试依赖Playwright Chromium，使用人工测试音与模拟麦克风，不使用真实参考录音。

GitHub Actions的Publish Recording Backup为手动工作流，push后需要手动运行pages.yml。发布检查采用文件白名单，不允许附带任何录音文件。更新app.js、spectrum.js或样式时，应同步更新index.html里的版本参数，避免混用缓存脚本。

## 实时频谱

连接麦克风后显示实时波形、音量以及可切换的频谱曲线和6秒滚动声谱图。使用原生AnalyserNode，FFT大小2048、平滑0.25、最高30次/秒，显示范围0至8kHz（不超过实际Nyquist频率）。

显示为数字FFT幅度，不是校准声压级或もごもご评分。分析不修改PCM录音，也不进入导出ZIP。断开麦克风清空显示；停止录音但仍连接麦克风时继续显示输入。


## 2026-10-14 台本更新

默认使用22句增强版：新增订单编号、金额、退款、月费、日期、电话、字母型号和配送地址，H/M共44条录音。数字与英字保留原稿写法，提示录制者在H/M中使用一致读法；没有擅自添加固定数字读音。

首次从15句版升级时自动新建22句会话。旧会话保留在列表，标有15文，可继续回听、录制和导出；其进度仍为30条，pairs.csv仍为15行。旧记录不自动复制到新会话。新会话保存自己的原稿快照，导出包含对应版本的原稿与SHA256。

输入文件的说明部分含旧参考指引和旧句数，构建时已改用现行文字指引并修正为22句，不恢复任何参考音频、姓名或相关入口。原始输入文件未改动。

## 2026-10-14 录制与回听流程修正

- 录制顺序为 H01 → M01 → H02 → M02，采用、前进和后退遵循同一顺序；仍可手动选择句子和条件。
- 每条录音停止后即保存至当前浏览器 IndexedDB。录音者/会话列表可切换参与者，右侧录音列表可直接播放对应 H/M；优先播放已采用的 take，否则播放最新 take。
- 垃圾桶按钮删除当前 take，需确认。删除已采用 take 会同时解除采用，不会自动采用其他 take，不影响同句另一条件。
- 全部 H/M 首次采用完成时自动生成并发起该参与者 ZIP 下载，包含全部 take；也可随时用“数据保存”手动导出。浏览器可能提示保存位置或阻止自动下载，请确认下载成功。
- 页面回听读取的是该设备、该浏览器、该站点中的本地记录，不是扫描电脑上的 ZIP。清除站点数据、使用无痕窗口、更换浏览器或设备会影响回听；因此 ZIP 是独立备份，不是自动上传。
